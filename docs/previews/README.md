- `trip-workspace.html`: self-contained browser preview. Download the file and open it locally; GitHub's file viewer displays source rather than running the page.
- `trip-workspace.fragment.html`: editable source of the interactive preview.

All parking observations are illustrative. Resource selection, phone preview and stale-feed controls only change the local preview. No camera inference, phone delivery, training or backend calls occur. The preview includes no credentials.

The proposed workflow keeps selected trip-related tabs and checkpoints alongside ParkSight's parking evidence. It does not replace the live map or claim that a public curb space can be reserved.
